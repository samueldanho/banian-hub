# SGA - Société Générale de l'Expertise Automobile

Site web officiel de SGA, cabinet d'expertise automobile indépendant à Abidjan.

## Description

SGA - Société Générale de l'Expertise Automobile est un cabinet d'expertise automobile indépendant spécialisé dans l'évaluation post-sinistre pour assureurs et particuliers.

### Services
- Expertise accident
- Expertise vol
- Expertise incendie
- Expertise bris de glace
- Rapports d'indemnisation
- Gestion VTC & assurances

## Technologies utilisées

- **Frontend**: React 18 + TypeScript
- **Build tool**: Vite
- **Styling**: Tailwind CSS
- **UI Components**: Radix UI + shadcn/ui
- **Router**: React Router
- **État**: TanStack React Query

## Installation et lancement

```bash
# Installation des dépendances
bun install

# Lancement en développement
bun dev

# Build pour production
bun build

# Lancer les tests
bun test
```
